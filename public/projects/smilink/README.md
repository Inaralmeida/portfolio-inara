# Capturas reais do Smilink

Copie os 20 arquivos PNG do ZIP `smilink-galeria.zip` para esta pasta, sem alterar os nomes.

Os caminhos, títulos e descrições das 20 capturas já estão configurados em `src/data/projects.ts`. O portfólio exibirá as imagens automaticamente depois do upload e deploy.

**Atenção:** antes de publicar, confira se as capturas não exibem dados pessoais ou informações privadas.
